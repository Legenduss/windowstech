# Changing Configs
## YASB
Open YASB Folder @ C:\Users\{Username}\.config\yasb

Add [YASB CONFIG](https://github.com/Legenduss/windowstech/blob/main/yasbconfig.yaml)

(Make sure you change the name from yasbconfig.yaml to config.yaml, I had to rename for both files to fit in the git. Should have 3 files (config.yaml, styles.css, and yasb.log)

Add [YASB CSS](https://github.com/Legenduss/windowstech/blob/main/styles.css)

On your Toolbar right click YASB and click Reload YASB

You can now close your YASB Folder

## GlazeWM

Open your GlazeWM folder @ C:\{Username}\Owner\.glzr\glazewm

Add [GlazeWM Config](https://github.com/Legenduss/windowstech/blob/main/config.yaml)

On your Toolbar right click GlazeWM and click Reload Config

Your install should be completed, enjoy your new windows.
